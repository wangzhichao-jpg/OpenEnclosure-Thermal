# 模型说明与适用范围（v0.1）

本文列出 v0.1 使用的全部方程、假设和拒绝规则。系数（U 值、K、Cd、过滤网阻力、风机曲线）都由用户提供，软件不内置经验默认值。

## M0 试验数据代数处理

- 温升 Δθ = 测点温度 − 环境参考温度。环境参考取用户指定的一个或多个环境测点的逐时平均值。
- 最终温升：试验末段 `final_window_min`（默认 10 min）内的平均值。
- t50/t63/t90：温升从首个有效值到最终温升，变化量首次达到 50%、63.2%、90% 的时刻（线性插值）。总变化量小于 0.5 K 时不计算。
- 最大升温速率：先做 5 min 滑动平均，再取 5 min 差分的最大绝对值。
- 稳定判据：对每个窗口结束时刻，计算窗口内温升的极差，以及线性回归斜率（K/h）。所有设定条件同时满足，即判为“满足用户判据”。报告同时给出末段窗口的结果，以及从哪个时刻起持续满足。

这一层只做数据处理，不含物理模型，也不作预测。

## M1 单测点一阶响应

恒定负荷下：

$$\Delta\theta(t)=\Delta\theta_0+(\Delta\theta_\infty-\Delta\theta_0)\left(1-e^{-(t-t_0)/\tau}\right)$$

- 用有界非线性最小二乘（scipy `least_squares`，TRF）拟合。$\Delta\theta_0$ 可以拟合，也可以固定为窗口首点。
- 标准误差按 $s^2(J^TJ)^{-1}$ 计算，前提是残差相互独立。残差呈系统性时，标准误差会被低估。
- 同一公式适用于降温曲线（$\Delta\theta_\infty<\Delta\theta_0$）。

| 条件 | 处理 |
|---|---|
| 有效点 < 6，或温升变化 < 0.5 K | 拒绝 |
| 参数触碰搜索边界 | 拒绝 |
| 窗口时长 < 1τ（未达最终变化量的 63%） | 拒绝：稳态温升与时间常数不可分辨 |
| 1τ ≤ 窗口时长 < 3τ | 警告：稳态温升为外推值 |
| Δθ∞ 与 τ 相关系数绝对值 > 0.95 | 警告 |
| Δθ∞ 相对标准误差 > 10%，或 τ 相对标准误差 > 20% | 警告 |
| 残差滞后 1 阶自相关 > 0.8 且 RMSE > 0.2 K | 警告：单一时间常数可能不足 |

真实测点往往有多个热路径和时间常数（例如触头的快速局部升温）。这时，一阶模型的 τ 是等效值，Δθ₀ 会吸收快速分量。

## M2 电流—稳态温升关系

$$\Delta\theta_\infty(I)=\Delta\theta_r\left(\frac{I}{I_r}\right)^n$$

- 只合并 `configuration` 相同的试验，不把改进前后的结构混在一起拟合。
- 输入是各试验 M1 识别出的 Δθ∞，状态为成功或警告的才采用。
- 只有 1 个电流水平（相差 2% 以内视为同一水平）时，拒绝识别。
- 只有 2 个电流水平时，给出两点精确解并发出警告，不提供不确定度。
- 识别出的 n 超出 1.0～2.5 时，发出警告，请检查数据。
- 预测只在识别电流范围内进行，超出范围默认拒绝。

导出参数可以直接对接 [switchgear-thermal-model](https://github.com/alliander-opensource/switchgear-thermal-model) 的 `Switchgear`（rated_current、measured_temperature_rise、temp_rise_exp、thermal_time_constant），用来计算负荷—温度时间序列。该包采用 MPL-2.0 许可，属于可选依赖。

## M3 单室空气节点通风模型

### 能量平衡（稳态）

$$Q_\text{int}+Q_\text{fan}=\dot m c_p (T_z-T_a)+\sum_i U_iA_i\,(T_z-T_{sa,i}),\qquad T_{sa,i}=T_a+\frac{\alpha_i G_i}{h_{o,i}}$$

- $T_z$ 为箱内充分混合空气节点温度，同时作为出口空气温度；进风温度取室外温度 $T_a$。
- U 值综合内外对流、辐射和壁板导热，由用户确定。常用的估算方法是 $1/U = 1/h_i + \delta/\lambda + 1/h_o$。
- $Q_\text{fan}$ 仅在风机设为“功率计入箱内热量”时计入。

### 压力平衡

$$\sum p_\text{fan}(V) + s\,g H(\rho_a-\rho_z) = \sum_j \Delta p_j(\dot m)$$

- 开口：$\Delta p = K\dot m^2/(2\rho A^2)$，或用流量系数表示，$K=1/C_d^2$。
- 过滤网：$\Delta p=\Delta p_r (V/V_r)^n \times$ 积尘倍数。
- 进风侧阻力件用室外空气密度，出风侧用箱内空气密度；按理想气体、常压计算。
- 浮力项：$s=+1$ 表示下进上出，浮力助推风机；$s=-1$ 表示上进下出，浮力削弱风机。自然通风时不计风机。
- 风机曲线只取稳定段，按流量递增排列，静压不增。转速比按相似律换算：$V\propto N$、$p\propto N^2$、$P\propto N^3$。并联台数平分风量。
- 每个位置（进风/出风）只能有一组运行风机，进出风两组按串联处理。

### 求解

- 先对 $T_z$ 做括号搜索，再用 Brent 法求解；每个 $T_z$ 下，再用 Brent 法求压力平衡的质量流量。
- 默认不外推风机曲线。系统阻力曲线与风机曲线在曲线范围内没有交点时，结果为“拒绝”，并说明是在低端还是高端无解。
- 报告给出能量平衡残差；残差超过 0.1% 时，结果判为失败。

### 适用范围与已知局限

- 单节点模型不能描述箱内温度分层、局部热点和气流短路。
- 不考虑风压（室外风）、渗漏缝隙和逆向流动的多解问题。v0.2 起将报告初值敏感性。
- 不含瞬态热容；时变工况在 v0.2 实现。
- 不计算辐射的方向性和遮挡，日照只按各面综合温度处理。

## 数值验证（tests/）

| 测试 | 对照 |
|---|---|
| 封闭箱 | $\Delta T = Q/UA$ |
| 封闭箱＋日照 | $\Delta T = Q/UA + \alpha G/h_o$ |
| 给定风量 | $\Delta T = Q/(\dot m c_p + UA)$ |
| 线性风机＋单开口 | 一元二次方程解析根 |
| 自然通风 | 浮力压差等于阻力和；$\dot m c_p\Delta T = Q$；高度增加时风量增加 |
| 过滤网积尘 | 积尘倍数增加时风量单调减小、温升单调增大 |
| 参数识别 | 5 组噪声种子下的参数恢复；截断曲线被拒绝；双时间常数数据报出结构性残差 |
| 上游对照 | switchgear-thermal-model 生成的曲线可被本软件识别回原参数 |
