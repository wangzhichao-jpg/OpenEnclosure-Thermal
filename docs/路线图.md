# 路线图

原则：每个版本都要完整可用；各验证层级分别报告，不把拟合效果写成预测精度。

| 版本 | 内容 | 验收要点 |
|---|---|---|
| **v0.1**（当前） | 温升试验分析器（导入、质量检查、温升曲线、用户稳定判据、一阶响应识别、电流指数、对比、限值比较）；单室通风快算（封闭/自然/强制/给定风量，风机—阻力工作点，过滤网积尘，日照，方案比较、扫描、敏感性）；中文 Excel 模板；HTML/Excel/JSON 报告；发布检查 | 解析解与合成数据测试全部通过；新用户 10 分钟内跑通示例 |
| v0.2 | 时变电流、环境温度、日照情景；单节点瞬态热容；多次试验联合校准；留出工况预测；多参数网格扫描与约束筛选；自然通风初值敏感性 | 留出预测误差与拟合误差分开报告 |
| v0.3 | 多隔室热—流网络（高压室—变压器室—低压室）；变压器损耗输入，以及箱内/箱外附加温升分析；可选 transformer-thermal-model 适配；本地图形界面 | 多节点质量和能量守恒；附加温升算例 |
| v0.4 | 电加热模型箱开放基准数据集（CC BY 4.0）；OpenFOAM 案例生成与探针结果导入；用 CFD/试验校正网络模型参数 | L2 基准：先校准再盲测，分别报告 |
| v1.0 | 数据格式和 API 稳定；至少三类公开基准；至少一个经书面授权的企业应用案例 | 版本兼容策略与长期维护说明 |

## 暂不纳入

- 电磁损耗与涡流计算
- 内置标准限值与“合格”判定
- 自研 CFD 求解器
