# 数据与合作

## 数据来源分类

每个项目文件都必须填写 `project.source_type`：

| 取值 | 含义 | 能否进入公开仓库 |
|---|---|---|
| `synthetic` | 合成数据 | 可以 |
| `public` | 已公开且许可允许再发布 | 可以，须注明出处和许可 |
| `own_test` | 自建试验，例如开放模型箱 | 可以，随数据许可发布 |
| `literature_digitized` | 从文献图表数字化得到 | 视原文许可而定；默认只作本地对照 |
| `enterprise_private` | 企业资料 | **不可以**，除非权利人书面同意 |

`oet check-release` 会拒绝以下内容：
- `enterprise_private` 或访问级别为 `internal/confidential` 的项目文件；
- 私有目录（`private_data/`、`customer_data/` 等）；
- 本机用户路径、访问令牌和私钥；
- 用户本地敏感词表中列出的词语。

## 标准与结论口径

- 仓库不复制 IEC、GB 等标准的条文、表格或计算全文。
- 稳定判据、温升限值等由用户录入，并注明来源。
- 输出只称作“工程分析结果”“模型预测”或“与用户设定限值的比较”，不称作认证、型式试验或认可检测结论。

## 合作方式

软件核心完整开源，不靠削减功能来促成付费。可以开展的合作：

1. **试验数据分析与模型校准**：企业数据在企业本地或约定的受控环境中处理。交付内容包括数据质量检查、热参数及其适用范围、模型能解释和不能解释的现象，以及补测建议。
2. **箱体散热方案比较与结构优化**：开口、百叶、风机、过滤网、隔室布置。
3. **多隔室网络、CFD 与样机验证**。
4. **开放基准共建**：共同设计试验，并按约定公开数据。

企业资料只有在合作约定允许的范围内才能使用。公开匿名案例须事先取得书面同意。
