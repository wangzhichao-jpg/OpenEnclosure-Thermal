# 电加热模型箱开放基准试验方案（L2）

**版本：** 方案 V0.1（2026-10）　**状态：** 规划，尚未实施
**数据许可（拟）：** CC BY 4.0　**对应软件版本：** v0.1 单室模型；v0.3 多隔室；v0.4 CFD 对照

## 1. 目的

开关柜和箱变的企业试验数据通常保密，第一次合作时也难以公开。本试验用**电加热器模拟设备发热**，建立一套几何、边界和测量条件全部公开的基准，用来：

1. 检验单室通风模型对浮力通风、风机—阻力工作点、过滤网积尘和外壳散热的预测能力；
2. 检验一阶响应识别在真实热惯性和噪声下的可辨识性；
3. 找出单节点模型失效的条件，例如热源位置、温度分层和气流短路，作为 v0.3 多隔室模型和 v0.4 CFD 对照的依据；
4. 留存一套可重复的方法，便于其他实验室复现。

**本基准不能证明：** 真实电气设备内部热点（触头、母排）的预测精度，也不能证明对任何企业产品适用。

## 2. 试验件

### 2.1 箱体

| 项目 | 方案 |
|---|---|
| 内部尺寸 | 1.0 m（宽）× 0.6 m（深）× 1.6 m（高），约为小型低压柜尺寸 |
| 箱体结构 | 1.5 mm 冷轧钢板，外表面喷涂（记录颜色，并测定太阳吸收率和发射率）；骨架用角钢；前门带密封条 |
| 可换面板 | 前下部进风窗：2 个 300 × 150 mm 插槽，可装盲板、百叶，或百叶加过滤网 |
| | 顶部或后上部出风窗：可装风机板（Ø120～172 mm 轴流风机 1～2 台）、百叶或防雨罩 |
| | 出风位置可选两档：后上部（有效高差约 1.2 m）和顶部（约 1.5 m），用来改变浮力高度 |
| 支撑 | 底部架空 100 mm，置于绝热垫块上，底面热损失单独标定 |
| 渗漏 | 封闭状态下做加压渗漏测试，记录 50 Pa 下的渗漏风量 |

### 2.2 热源

| 项目 | 方案 |
|---|---|
| 加热模块 | 3 个带铝散热片的电阻加热板，每个 0～500 W；可分别安装在下、中、上三层支架上 |
| 供电 | 优先用可编程直流电源，或交流调压器加真有效值功率计；功率测量准确度优于 ±0.5% |
| 安全 | 每个加热模块配温控开关（120 °C 断开）和热熔断器；箱体接地；剩余电流保护；箱内最高温度超限时联锁断电 |

### 2.3 日照模拟（可选）

在顶板外表面粘贴电热膜（0～400 W），以已知热流模拟被吸收的日照，并用功率计计量。这样比红外灯阵更容易重复。数据中按“外表面吸收热流”记录，并说明它与 $\alpha G$ 的等效关系。

## 3. 测量

| 量 | 测点 | 仪表与要求 |
|---|---|---|
| 箱内空气温度 | 9 点：3 个高度 × 3 个水平位置；另在进风口和出风口截面各设 2 点 | T 型热电偶（Ⅰ级），加防辐射罩；试验前与参考铂电阻在 2～3 个温度点比对 |
| 壁面温度 | 6 个内表面和 6 个外表面，各取中心点 | 热电偶用导热胶粘贴，外表面贴片的发射率与漆面一致 |
| 热源表面 | 每个模块 1 点 | 热电偶 |
| 环境温度 | 3 点：距箱体 1 m，分别位于下、中、上高度 | 防辐射罩；记录 0.2 m/s 以下的环境风速 |
| 加热功率 | 每个模块 | 功率计 ±0.5% |
| 风量（强制通风） | 进风侧 | 喷嘴流量箱加辅助风机，使箱内外压差为零（零压差法），目标不确定度 ±3% |
| 风量（自然通风） | 全箱 | CO₂ 示踪气体恒定注入法（目标 ±10～15%），同时用能量平衡交叉核对 |
| 压差 | 过滤网前后、进风百叶前后、箱内对环境、风机前后 | 0～250 Pa 差压变送器，±0.5% FS |
| 风机 | 电压、电流、功率、转速 | 风机曲线单独在风量台上测定，作为模型输入 |
| 采样 | 全部通道 | 10 s 一次，同步记录 |

**温差不确定度目标：** 空气温升的扩展不确定度约 0.3 K（k=2）。各项不确定度在每次试验的数据说明中逐项给出。

## 4. 试验矩阵

功率 P 为 3 个模块的合计。“稳定”按事先登记的判据判断：所有空气测点 30 min 内变化 ≤ 0.3 K。该判据随数据一同发布。

| 组 | 目的 | 变量与水平 | 次数 |
|---|---|---|---|
| A 封闭箱 | 外壳总 UA、热时间常数 | P = 300 / 600 / 900 W，热源均布 | 3 |
| B 自然通风 | 浮力通风模型 | 进出风净面积 3 档 × 出风高度 2 档 × P = 600 / 1200 W | 12 |
| C 风机通风 | 风机—阻力工作点 | 风机电压 3 档 × 台数 1 / 2，P = 1200 W | 6 |
| D 过滤网 | 积尘阻力对风量和温升的影响 | 洁净，以及加叠孔板模拟积尘 2 档（预先测定阻力曲线）× 强制 / 自然 | 6 |
| E 热源位置 | 单节点模型适用边界、温度分层 | 单模块 600 W 置于下 / 中 / 上 × 强制 / 自然 | 6 |
| F 瞬态 | 动态参数识别 | 0→1200 W 阶跃、1200→600 W 降档、断电冷却 × 封闭 / 强制 | 6 |
| G 日照模拟（可选） | 外表面得热 | 顶板电热膜 0 / 200 / 400 W × 强制 / 自然 | 4～6 |

合计约 43～45 次。稳态工况每次 4～8 h，共需约 25～35 个试验日。第 2、3 组之间安排 1 次重复试验（A 组 600 W），用于检查重复性。

## 5. 校准与盲测设计

为避免“拟合好看”被当成预测能力，按以下顺序进行，并公开每一步的结果：

1. **测定输入参数**：风机曲线、过滤网和百叶的阻力曲线在风量台上单独测定，并且在模型比对之前完成。
2. **校准集**：用 A 组标定外壳 UA；用 C 组中的 2 个工况标定开口阻力 K。
3. **冻结参数**：把参数写入带 SHA-256 的模型文件并公开。
4. **留出预测**：用冻结后的参数预测 B、C（其余）、D、G 组。分别报告空气温升和风量的误差，不以单一平均值掩盖局部偏差。
5. **失效分析**：E 组用来报告单节点模型在热源位置改变时的偏差，作为多隔室模型和 CFD 的输入。

比对时，模型给出的是“空气节点温度”。实测值对应两个量：出口截面空气平均温度，以及 9 个空气测点按体积加权的平均温度。两者都要报告。

## 6. 数据发布格式

每次试验一个目录，可直接用 `oet analyze-test` / `oet ventilate` 读取：

```text
benchmark-box/
├─ README.md                 # 试验件、仪表、已知问题、许可
├─ geometry/                 # 图纸（PDF/DXF）、照片、测点位置图
├─ instruments.yaml          # 仪表型号、量程、校准日期、不确定度
├─ box_model.yaml            # 对应 oet 箱体模型（冻结参数版本带 SHA-256）
└─ runs/
   ├─ A1_closed_300W/
   │  ├─ project.yaml        # oet 试验项目文件，source_type: own_test
   │  ├─ raw.csv             # 原始记录（不改动）
   │  └─ log.md              # 运行日志、异常、门开合等事件
   └─ ...
```

数据按 CC BY 4.0 发布，可选择在 Zenodo 申请 DOI。数据说明须写明适用范围和已知问题。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 自然通风风量太小，难以测准 | 示踪气体与能量平衡双方法；报告不确定度，不强行给出精度结论 |
| 环境温度漂移 | 在环境舱或大空间实验室进行；环境测点 3 点平均，报告漂移量 |
| 热电偶受辐射影响 | 空气测点加防辐射罩；热源附近的测点单独标注 |
| 过滤网积尘难以复现 | 用已知阻力的孔板或网层叠加来模拟，并在报告中说明这与真实积尘不同 |
| 模型箱与真实设备差异 | 在数据说明和论文中明确：只验证通风散热网络，不涉及导体热点 |

## 8. 产出

1. 开放数据集，以及配套的 `oet` 项目文件；

3. 软件 v0.4 发布时附基准对照结果；
4. 可选：论文或会议报告。
