# 快速上手

## 1. 安装

需要 Python 3.11 或 3.12。

```bash
git clone https://gitee.com/bigtaurus/OpenEnclosure-Thermal.git     # 或 GitHub
cd OpenEnclosure-Thermal
python -m venv .venv
.venv\Scripts\activate
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -e ".[test]"
pytest -q                     # 可选：运行自动测试
```

## 2. 用示例走一遍（约 5 分钟）

```bash
oet init demo
oet analyze-test demo/switchgear_test/switchgear_test.yaml --compare R1:R2 -o out_test
oet ventilate demo/box_ventilation/box_ventilation.yaml -o out_box
```

用浏览器打开 `out_test/test_report.html` 和 `out_box/ventilation_report.html`。

示例是一台**虚构**开关柜的四次温升试验：

| 试验 | 电流 | 配置 | 文件格式 |
|---|---|---|---|
| R1 | 1250 A | baseline | 记录仪导出：日期时间＋中文列名，含一个跳点和一个缺测 |
| R2 | 1250 A | improved（通风改进） | 分钟＋测点编号列名 |
| R3 | 1000 A | baseline | 秒 |
| R4 | 800 A | baseline | 秒 |

R1、R3、R4 属于同一配置，可用来识别电流—温升指数。R2 只参与改进前后的对比。

## 3. 用自己的试验数据

### 方式 A：Excel 模板

```bash
oet template test 我的温升试验.xlsx
```

1. 在“项目”表中填写数据来源。企业数据填 `enterprise_private`。
2. 稳定判据由你自己设定，并在“判据来源”中注明依据。
3. 在“测点”表中登记测点编号；环境测点的类别填 `ambient`。
4. 在“试验”表中登记试验。数据可以直接放在本工作簿中，按“数据_R1”表的格式填写：第 1 行是说明，第 2 行是列名（时间列＋测点编号）。数据也可以放在外部 CSV 文件中。
5. 运行 `oet analyze-test 我的温升试验.xlsx -o 报告目录`。

### 方式 B：YAML

参照 `demo/switchgear_test/switchgear_test.yaml`。常用字段：

```yaml
test_runs:
  - id: R1
    file: 原始记录.csv              # 相对于本 YAML 的路径
    time: {column: 记录时间, kind: datetime}   # seconds / minutes / hours / datetime
    columns: {T01: "CH01 母排连接处"}   # 测点编号: 原始列名；未列出的测点按编号找列
    ambient: [TA1, TA2]             # 多点取平均
    load: {current_A: 1250}
    configuration: baseline         # 同一结构/通风配置
    align_offset_min: 0             # 对比时的时间偏移（如通电时刻）
stability:
  window_min: 60
  max_change_K: 1.0                 # 可再加 max_rate_K_per_h
  source: "依据 ×× 标准 ×× 条款，由试验负责人设定"
fits: auto                          # 或列出 run/sensor/start_min/end_min
```

先用 `oet validate 项目.yaml` 检查格式和列映射，再运行分析。

## 4. 箱体通风快算

```bash
oet template box 我的箱体.xlsx
oet ventilate 我的箱体.xlsx -o 报告目录
```

- **壁面**：填写各面的面积和 U 值。日照强度、吸收率、外表面换热系数可以留空，留空时不计日照。
- **阻力件**：`opening` 需填写净面积，以及 K 或 Cd 中的一个；`filter` 需填写额定风量、额定阻力、指数 n 和积尘倍数。
- **风机曲线**：选用厂家曲线的稳定段，按风量从小到大填写。
- **方案**：参数路径的写法，例如：
  - `internal_heat_W`
  - `ambient.temperature_C`
  - `ventilation.mode`
  - `fans[F1].count`
  - `fans[F1].speed_ratio`
  - `elements[FL1].loading_factor`
  - `elements[IN].area_m2`
  - `surfaces[*].solar_irradiance_W_m2`（`*` 表示全部）
- **扫描**：对一个参数路径给出一组取值，用逗号分隔。

## 5. 其他命令

| 命令 | 用途 |
|---|---|
| `oet fit 项目 --run R1 --sensor T01 --start 30 --end 400` | 对单个测点指定窗口拟合，输出 JSON |
| `oet convert a.yaml b.xlsx` | YAML、JSON、Excel 互转 |
| `oet check-release 目录 --denylist 本地敏感词.txt` | 公开发布前检查私有数据、本机路径和凭据 |

## 6. Python API

```python
from open_enclosure_thermal.workflows import analyze_test_project, ventilate_project
from open_enclosure_thermal.reporting import write_report

rep = analyze_test_project("project.yaml", compare=[("R1", "R2")])
for f in rep.fits:
    print(f.run, f.sensor, f.status.value, f.value("rise_inf_K"), f.value("tau_min"))
write_report(rep, "out")
```
